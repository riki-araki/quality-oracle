# 意思決定ログ（decisions/）

このフォルダは、設計・戦略上の判断を「1判断1ファイル」で蓄積する場所。
後から「なぜこう決めたか」を辿れるようにするのが目的（ADR: Architecture Decision Record の簡易版）。

## 書き方
- ファイル名: `NNNN-短い説明.md`（連番）。例: `0002-local-execution.md`
- 中身のテンプレ:

```
# NNNN. タイトル

- 日付:
- ステータス: 採用 / 保留 / 撤回 / 置換（→ NNNN）

## 背景 / 何を決めるか

## 決定

## 理由

## 捨てた選択肢とその理由

## 影響・前提（後で覆すとき確認すべきこと）
```

## 方針
- 判断を変えたら、古いファイルは消さずステータスを「撤回／置換」にして新ファイルを足す。
  経緯（なぜ前はそう考え、なぜ変えたか）が最大の資産。
