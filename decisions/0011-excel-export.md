# 0011. 課題/プロジェクトを Excel(.xlsx) にエクスポート（試験項目＋証跡）

- 日付: 2026-06-28
- ステータス: 採用

## 背景 / 何を決めるか
手動テストの集約・共有（Backlog 等で先方へ）のため、試験項目と証跡を Excel で出力したい。
「課題単位／プロジェクト単位」で出せると活用の幅が広がる。

## 決定
1. **1課題=1シート**の .xlsx を出力する。
   - 列: No / 種別(回帰・既知バグ) / リスク / タイトル / Given / When / Then / 宣言した意図 / 最新結果 / 結果履歴 / 証跡(ファイル名)。
   - **証跡画像をシートに埋め込む**（PNG/JPEG/GIF。WebP は埋め込まずファイル名のみ）。
2. **課題単位**（`/api/export/issue/[id]`）と **プロジェクト単位**（`/api/export/project/[id]`・課題ごとにシート）の両方。
   管理画面と Project ダッシュボードに「Excel出力」リンク。
3. ライブラリは **exceljs**（画像埋め込み対応・無料）。画像は base64 で addImage。

## 理由
- §7 の手動テスト工程・共有を直接支援。Excel は先方とのやり取りで最も流通する形式。
- exceljs は画像埋め込みができ、自前実装より圧倒的に堅実（依存追加の価値あり）。

## 捨てた選択肢とその理由
- **SheetJS(xlsx)**: 無料版は画像埋め込みが弱い。証跡画像が要件なので exceljs。
- **CSV**: 画像を含められない。共有用途で見栄えも劣る。

## 影響・前提（後で覆すとき確認すべきこと）
- 大きなスクショを多数含むと .xlsx が肥大化する（サムネ縮小やリンク化は将来検討）。
- 証跡ファイルは `data/evidence/`（ローカル）から読む。ホスト化時は保存先抽象（0006/0002）に合わせる。
- 運用注意（自戒）: 一時テストの後始末で `data/evidence` 全体を削除しない（証跡ファイルはユーザー資産）。
