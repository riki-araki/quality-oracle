# 0015. テスト用HTTPリクエストのAI生成 ＋ 送受信(テキスト証跡)のExcel/一覧反映

- 日付: 2026-06-28
- ステータス: 採用

## 背景 / 何を決めるか
- HTTPコンソール（0014）の送受信が **Excelエクスポートに入っていない**／一覧で見えづらい。
- テスト用リクエストの内容を **AIで下書き**したい。

## 決定
1. **AIでリクエスト下書き**：項目（観測・質問・宣言した意図・生成テスト）＋課題のAI分析ナレッジから、
   method/url/headers/body を AI が下書きする（`docs/prompts/request-gen.md`・単一の真実源）。
   - ホスト不明時は `http://localhost:3000` を仮ベースにする。**人が確認・修正してから送信**（判定も人）。
2. **送受信を Excel に反映**：1課題=1シートに「送受信・テキスト証跡」列を追加し、テキスト証跡（HTTP送受信）の
   内容を載せる（4000字で切り詰め）。画像は埋め込み、テキストは内容をセルに表示。
3. **一覧の証跡カウントはテキストも含む**（📎は画像＋テキストの合計）を確認・明記。

## 理由
- 「curlで確かめる」観点は、AIがリクエストの叩き台を作れると着手が速い（ナレッジがあれば精度も上がる）。
- 送受信は API テストの証跡。Excel共有（§7）に載らないと意味が薄いので反映する。

## 捨てた選択肢とその理由
- **AIがリクエストを生成して自動送信/自動判定**: ガードレール（自動ランナー）に逆戻り。下書きまで＝人が送る。
- **テキスト証跡を画像化してExcelに**: 不要に重い。テキストはセルに直接載せる。

## 影響・前提（後で覆すとき確認すべきこと）
- AI下書きは URL/認証が不確かなことが多い。**人の確認前提**（雛形にも明記）。
- Excel のテキスト証跡は 4000 字で切り詰め。全文はアプリ内 or 証跡ファイルで確認。
