# セミナー申込フォーム — 仕様

社内セミナーの申込を受け付けるフォームを作ってください。参加費は有料です。

## 機能

### 1. 申込フォーム
- 氏名・メールアドレス・所属を入力する
- 参加するセミナーを一覧から選ぶ
- 「申し込む」ボタンで送信する

### 2. 定員
- セミナーごとに定員がある
- 定員に達したセミナーには申し込めない

### 3. 締切
- セミナーごとに申込締切日がある
- 締切を過ぎたセミナーには申し込めない

### 4. 決済
- 申込と同時に、参加費をカード決済する
- 決済が成功したら、申込完了メールを送る

### 5. キャンセル
- 申込者は、自分の申込をキャンセルできる
- キャンセルすると返金される

## 技術
- Node.js
- データはメモリ上の配列で持ってよい（DBは今回不要）
- 決済とメール送信は、外部APIを呼ぶ関数として用意されているものを使う
